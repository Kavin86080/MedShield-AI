Adversarial Robustness Dashboard

Phase 2 development pipeline. Designing testing blocks to protect clinical models from adversarial cyberattacks.

Single Pixel Attack
Phase 2.1

Evaluates model resilience by altering a single pixel value in X-ray images, testing if minor isolated input modifications can force false classifications.

Sparse Perturbations
Phase 2.2

Tests models against localized pixel clusters and structured noise overlays (e.g. FGSM/PGD attacks) to measure robustness during raw data degradation.

Defense Engine
Phase 2.3

Implements adversarial training, input denoising, and digital purification blocks to restore high-confidence classifications under active data corruption.

Robustness Scoring
Phase 2.4

Compiles standard metrics (Attack Success Rate, Defended Model Accuracy, Perturbation Distance) into a global robustness evaluation score.
